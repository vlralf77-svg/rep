# ⚽ 프리킥 챌린지 (Free Kick Challenge)

방향과 파워 게이지를 골라 골을 넣는 간단한 모바일 친화 축구게임입니다.
별도 설치나 빌드 없이 **`index.html` 파일만 열면** 바로 플레이할 수 있습니다.

## 플레이 방법

총 **5번의 킥** 동안 최대한 많은 골을 넣으세요.

1. **방향 선택** — 좌우로 움직이는 노란 조준선이 원하는 위치에 왔을 때
   버튼(또는 화면)을 눌러 방향을 고정합니다.
2. **파워 선택** — 오른쪽 게이지가 오르내립니다. 초록색 적정 구간에서
   누르면 좋은 슛이 됩니다. (너무 세면 골대 위로 넘어가요!)
3. 공이 날아가고 **골키퍼가 다이빙**합니다. 골키퍼를 피해 골대 안에
   넣으면 득점!

## 조작

- 화면 아무 곳이나 탭하거나, 하단 버튼을 눌러 진행합니다.
- 모바일 / 데스크톱 브라우저 모두 지원합니다. (터치 + 마우스)

## 실행

```bash
# 가장 간단한 방법: 파일을 브라우저로 열기
open soccer-game/index.html      # macOS
xdg-open soccer-game/index.html  # Linux

# 또는 로컬 서버로 실행
cd soccer-game && python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 기술

- 순수 HTML5 Canvas + Vanilla JavaScript (의존성 없음)
- 최고 점수는 브라우저 `localStorage`에 저장됩니다.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 게임 화면 구조 |
| `style.css` | 스타일 및 반응형 레이아웃 |
| `game.js` | 게임 로직 (조준 / 파워 / 골키퍼 / 판정) |
