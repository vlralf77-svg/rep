# ⚽ 3D 프리킥 챌린지 (3D Free Kick)

진짜 3D 그래픽(WebGL)으로 만든 프리킥 게임입니다. 입체적인 잔디 구장,
실제 골대와 그물, 회전하는 3D 공, 다이빙하는 골키퍼, 공을 따라가는 카메라가
들어 있습니다. 설치 없이 브라우저에서 바로 플레이됩니다.

> 평면(2D) 버전은 [`../soccer-game`](../soccer-game) 폴더에 있습니다.

## 플레이 방법

총 **5번의 킥** 동안 최대한 많은 골을 넣으세요. 조작은 2단계입니다.

1. **방향** — 골문을 좌우로 움직이는 노란 마커가 원하는 위치에 왔을 때
   버튼(또는 화면)을 눌러 방향을 고정합니다.
2. **파워** — 오른쪽 게이지가 오르내립니다. 초록 구간에서 누르면 좋은 슛이
   됩니다. 너무 세면 골대 위로 넘어갑니다.
3. 공이 3D 궤적으로 날아가고 **골키퍼가 다이빙**합니다. 키퍼를 피해
   골대 안에 넣으면 득점!

## 기술

- [Three.js](https://threejs.org/) (CDN, ES Module `importmap`)
- WebGL 렌더링, 그림자, 포물선 물리, WebAudio 효과음
- 외부 빌드/설치 불필요 — `index.html`만 열면 됩니다.
- 최고 점수는 브라우저 `localStorage`에 저장됩니다.

## 실행

```bash
# 로컬 서버로 실행 (ES module은 file:// 에서 CORS 제한이 있어 서버 권장)
cd soccer-game-3d && python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

> 인터넷 연결이 필요합니다(Three.js를 CDN에서 불러옵니다). GitHub Pages로
> 배포하면 링크만으로 어디서든 플레이할 수 있습니다.

## 파일 구성
