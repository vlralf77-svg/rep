# 영상통화 PWA 웹푸시 백엔드

앱(웹/PWA)이 **닫혀 있어도 전화 알림(벨)** 이 뜨게 해주는 작은 서버입니다.
누군가 전화를 걸면 상대 기기로 **웹푸시**를 보내 알림이 울립니다.
실제 영상·음성은 여전히 브라우저끼리 **P2P**로 흐르고, 이 서버는 "전화가 왔다"는
신호(푸시)와 정적 웹앱 서빙만 담당합니다. → **안드로이드·iOS 둘 다** 동작.

## 무료 배포 (Render)

이 저장소 루트의 `render.yaml` 에 `videocall-push` 서비스가 정의돼 있습니다.

1. https://render.com 에 GitHub 계정으로 가입
2. **New → Blueprint** → 이 저장소 선택 → **Apply**
3. 생성되는 주소(예: `https://videocall-push-xxxx.onrender.com`)가 통화 앱 주소입니다.
   - 정적 웹앱을 이 서버가 함께 서빙하므로, **이 주소 하나**로 전화·수신이 모두 됩니다.

## 사용 (전화급)

1. 두 사람이 각자 위 주소의 `/phone.html` 을 열고, **홈 화면에 추가**(설치)합니다.
   - 안드로이드 Chrome: 메뉴 → "홈 화면에 추가"
   - iOS Safari(16.4+): 공유 → "홈 화면에 추가" → 설치된 앱을 한 번 실행
2. 앱을 열어 **내 아이디로 접속**하고 **알림 권한을 허용**합니다.
3. 상대 아이디로 **전화 걸기** → 상대 앱이 닫혀 있어도 **알림(벨)** 이 뜹니다.
   알림을 누르면 앱이 열리며 연결됩니다.

## 엔드포인트

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/vapidPublicKey` | 클라이언트 구독용 공개키 |
| POST | `/subscribe` | `{ userId, subscription }` 구독 등록 |
| POST | `/unsubscribe` | `{ userId, endpoint }` 구독 해제 |
| POST | `/call` | `{ from, to }` 상대에게 푸시(벨) 발송 |
| GET | `/healthz` | 헬스체크 |

## 환경 변수

| 변수 | 설명 |
|------|------|
| `PORT` | Render 가 자동 주입 |
| `VAPID_PUBLIC` / `VAPID_PRIVATE` | (선택) 고정 VAPID 키. 없으면 자동 생성 |
| `VAPID_SUBJECT` | 연락처(mailto:) |
| `DATA_DIR` | 구독/키 저장 폴더 (기본: 앱 폴더) |

> ⚠️ **무료 플랜 한계**: 디스크가 초기화될 수 있어, 서버가 재시작되면 저장된 구독이
> 사라질 수 있습니다. 이 경우 각자 앱을 한 번 열면 자동으로 다시 구독되어 복구됩니다.
> VAPID 키를 `env` 로 고정해두면 구독이 더 오래 유지됩니다.
> "완전히 닫힌 상태에서도 항상" 보장하려면 상시 디스크(유료) 또는 항상 켜진 호스트가 유리합니다.

## 한계 (정직하게)

- 이 방식은 **알림(소리·진동) 수준**입니다. iOS 잠금화면을 꽉 채우는 CallKit 통화 화면은
  Apple 개발자 계정 + 네이티브 앱이 필요해 여기서는 다루지 않습니다.
- iOS 는 반드시 **홈 화면에 추가(PWA 설치)** 해야 웹푸시가 동작합니다(브라우저 탭만으로는 X).
